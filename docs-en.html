ATELIER is an online boutique with a built-in AI assistant named Aria, who talks to shoppers like a seasoned stylist: curates outfits, advises on sizing, tracks orders, and answers questions about shipping and returns. 02Architecture

How it works

The path from a customer's question to a beautiful answer — in a few seconds.

01

The customer writes in the chat

Aria greets the visitor and offers quick prompts — "Help me with sizing," "Where's my order," "Style me an outfit." The conversation feels like a regular messenger.

02

The system gathers context

The question is enriched with up-to-date store information: the catalogue with stock levels, policies, size charts, the customer's orders, and the bot's personality. Aria always answers from real data, never makes things up.

StoreContextZustandlive stock
03

The AI crafts the answer

The request goes to n8n, where the GPT-4o model runs with your brand's instructions. It decides what to say and which card to show — for example, order tracking or a product selection.

n8n webhookGPT-4obrand persona
04

The answer comes alive as a card

The app turns the response into a visual element: a delivery timeline, product carousels, a size chart, or a policy quote — with photos, prices, and statuses.

order timelineproduct carouselsize chart
05

Everything is stored in Supabase

Every exchange lands in a secure database. The admin panel shows conversations in real time and computes analytics. Data access is strictly scoped by security rules.

PostgreSQLRow-Level Securitylive feed
06

A fallback engine that never goes down

If the AI service is temporarily unavailable, a local assistant kicks in and answers on its own. The store and the chat always keep working.

💡This guarantees that a client demo or a live storefront never "freezes" because of an external outage.

05Launch

What it takes to go live

Five steps from zero to a live store with an AI concierge.

Create a Supabase project

A cloud database to hold accounts, orders, the catalogue, and all conversations. The free tier is plenty to start.

Apply the data schema

A ready set of migrations creates all the tables and sets up the security rules (who sees what). It runs in a few clicks.

Connect the AI brain

Import the ready-made n8n workflow and paste in your OpenAI key. This is where Aria's intelligence "lives" — keys never reach the browser.

Fill in the settings

Add the Supabase and n8n addresses to the config file. Without them the store still works — in demo mode with sample data.

Build and deploy

A single command builds the finished site into static files that drop onto any server or VPS. To update — just rebuild.
